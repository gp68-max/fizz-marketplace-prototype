# Owl Market – Fizz Marketplace mini prototype

A tiny one-page web prototype that mimics the Fizz Marketplace at Rice University, built for an individual class assignment.

- **Live page:** https://gp68-max.github.io/fizz-marketplace-prototype/
- **Button:** click **"+ Sell something"** to post a new (fake) listing to the top of the feed and show a confirmation message.

Built with plain HTML/CSS/JS and AI assistance (Claude). Not affiliated with Fizz; all listings are fake.
